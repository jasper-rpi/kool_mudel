Programmi kasutamiseks vajutage kõrval olevale "Releases" kirja all olevale 1.0 nupule. See viib teid ühele lehele, kust peate vajutama "KoolWindows.zip" tekstile, see laeb alla programmi failid .zip arhiivis, millest peate failid välja võtma. Programmi käivitamiseks topelt klikkige "kool.exe" failile. Programmis ringi liikumiseks kasutage klaviatuuril W, A, S, D nuppe ja ringi vaatamiseks hiirt.
